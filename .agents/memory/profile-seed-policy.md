---
name: Profile seed policy
description: Creator-supplied editable defaults must replace fictional sample personas
---

GYM Buddy profile defaults should use the creator's supplied details, not a fictional sample person. Profile details must remain editable.

**Why:** The user explicitly asked for their own details because they are making the app and do not want a random person's name shown.

**How to apply:** Refer to current application defaults for the actual values; do not duplicate personal details in memory. Preserve customized saved values when upgrading legacy sample data.
